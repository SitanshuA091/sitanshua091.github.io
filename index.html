Tiny-Qwen

LLM from scratch

A scaled-down Qwen3 implementation built from scratch with support for both Dense Transformer and Mixture-of-Experts language models using a shared training framework.

Python, PyTorch, NumPy

A modular vector-search benchmarking library for comparing FAISS index types across recall@k, latency, and memory trade-offs on real datasets.

Python, NumPy, FAISS, Retrieval
